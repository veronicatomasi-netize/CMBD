** Projetos Banco de Dados de um Sistema de Vendas **

Este projeto foi desenvolvido para a criação de banco de dados relacional
aplicado a um Sistema de Vendas

A primeira parte do projeto contém a representação do modelo do DB atráves de
um diagrama de entidade-relacionamento.

Criação de Tabelas:
  -Clientes;
  -Produtos;
  -Pedidos;
  -Fornecedores;
  -Compras.

O projeto possui um código fonte revisado e documentado.
